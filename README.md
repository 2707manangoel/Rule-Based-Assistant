# Rule-Based Personal Assistant

A simple command-line personal assistant built using Python. It interacts with users through a menu and performs tasks based on their choices.

## Features

- Personalized greeting using the user's name
- Programming joke generator
- Motivational messages
- Current date and time display
- Interactive menu
- Input handling and exit functionality

## Technologies Used

- Python 3
- `datetime` module
- Functions
- Conditional statements
- Loops
- User input and f-strings

## Requirements

- Python 3 installed
- Visual Studio Code or any Python-compatible editor

## How to Run

1. Open the project folder in your terminal.
2. Run the following command:

   ```bash
   python3 assistant.py
   ```

3. Enter your name and choose an option from the menu.
4. Follow the displayed instructions to interact with the assistant.
